项目分析

一、从四个维度分析影响广告转化效果的因素

（1）用户维度：

-用户历史行为（用户过去点击、浏览、购买记录，代表用户真实购买意向。有过同类商品浏览、点击行为的用户，点击广告之后下单转化概率明显更高）

-用户画像属性（用户年龄等级、消费能力、用户等级；不同消费层级用户，下单意愿差异明显）

（2）商品 / 店铺维度

-商品类目：不同一级商品类目天然转化差距巨大；部分类目属于高客单价决策型商品，转化路径长，转化概率偏低；快消类商品转化概率更高。

-商品本身热度：商品历史销量、收藏量，热门商品更容易促成购买。

-店铺质量：店铺评分、服务、物流表现，店铺基础越好，用户点击后下单可能性越高。

（3）广告投放维度

-广告品牌信息：品牌对转化拉动明显，知名品牌广告转化高于普通杂牌商品。

-广告计划、投放ID：不同广告投放方案，面向人群不同，带来的点击样本质量不一样；劣质投放渠道会带来大量低转化点击，拉低整体 CVR。

（4）上下文场景维度

-时间特征：星期、小时，购物高峰时段（晚间）转化高于工作日白天。

-搜索词匹配度：用户搜索关键词和广告商品匹配程度，搜索意图和商品越贴合，转化越高；搜索词和广告不匹配，即使产生点击，也很难下单。

二、项目任务
1. 完成多份原始数据集读取、路径适配、数据表合并，开展数据清洗与预处理；
2. 进行探索性数据分析，理解数据分布，识别业务与数据问题；
3. 完成特征工程，构造业务可用特征，区分类别特征与连续特征；
4. 按照时间切分训练集与验证集，规避时序数据泄露；
5. 使用 LightGBM 构建 CVR 二分类预测模型，处理样本不平衡、过拟合等问题；
6. 在测试集上进行预测，输出预测结果文件 submit.csv。
